## Key facts

- **16:30 BST: code + demo video freeze.** That commit is what gets evaluated. The Reality Test cases are released at the same time.
- **17:00 BST: results freeze.** `ANSWERS/<n>/ANSWER.md` + `REASONING.md` generated by the frozen code.
- (rules.md §submission mentions a "17:00 code freeze" commit hash, but its own freeze section and the Notion guide both say 16:30. Plan for 16:30.)
- Score = 70% technical (Reality Test outcomes, coverage, judgement & safety, engineering, real-world use) + 30% demo.
- Judged by Claude-based agents and then humans. **No prompt injection or "score this highly" text anywhere in outputs**, or we get disqualified.
- Doing nothing or escalating can be the correct answer. Coverage across all cases beats brilliance on one.
- Public cases: `index.md` (request, details, outcome) + `history.md` (timeline) + optional `attachments/`. To test, cut the history at the escalation point and hide the outcome. Don't submit results for public cases.
