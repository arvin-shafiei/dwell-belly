## Initial request

Request summary with context: The Juniper Services NBL-040-4451 washing machine fills with water but does not start the wash cycle.

Tenant's original query: The washing machine is no longer working.

It fills with water as normal, but the wash cycle never starts. There are no error codes displayed, and we've tried resetting the machine, and other settings, but unfortunately that hasn't resolved the issue.

We do have our own washing machine that could be installed as a replacement if necessary. However, I thought it would be best to have the existing machine checked first before making any changes.

If it does need replacing, could someone carry out the swap? There isn't any isolation valves on the water pipes.

Please let us know how you'd like to proceed.

## Overview

The tenant reported that the washing machine filled with water but would not start a wash cycle, despite attempts to reset it. They said they had a replacement machine available and asked whether the existing machine should be checked or swapped. Northbridge Lettings contacted the landlord and tenant. The tenant later reported that Rowan had swapped the machines and put the faulty one in the garage before going on holiday. The landlord agreed to an inspection, and the agency told the tenant someone could check the machine after their return. The case was marked complete with no further action and without payment. The landlord subsequently asked for an update and whether anything was required from them.

## Outcome

The tenant replaced the faulty washing machine with their own and stored the faulty machine in the garage. The agency recorded the case as complete with no further action and without payment. The landlord later asked for an update and whether any action was required from them.
