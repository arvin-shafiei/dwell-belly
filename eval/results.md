# Eval results

Generated by `node scripts/eval/report.mjs` from saved eval runs. Not edited by hand.

How to read this: every case is run through the agent (`npm run eval -- --agent flow`), then scored against an answer key. Disposition and channel are checked in code; whether the right party was addressed, whether the content is right and whether a must-never rule was broken are judged by a model. Each score comes from one run, and the agent is not deterministic, so small differences between runs are noise.

## What these two runs are, and what they are not

- **The sample:** the same 48 cases in both runs: 12 organiser practice cases and 36 generated cases (3 from each of 12 difficulty patterns). The full sets are 50 and 243.
- **Run 1 to run 2 changed three things at once:** the models (all Opus 5.5, then Opus for the deciding step and Sonnet 5.5 for reading and checking), the planner's guidance, and one eval rule (a request routed through a visible team is accepted when the answer key names a team that appears nowhere in what the agent is shown; 22 of the 50 practice keys do this). The difference between the columns cannot be attributed to any one of them.
- **Neither run is the current code.** After run 2, two of its three failures were fixed and re-run individually (`gen-408`, `gen-501`: both now send their messages), the decision card's schema changed, and a critic retry was added. The 48 cases have not been re-scored as a set since.
- **Views:** practice cases were scored without their title and Context section, which often state the answer. The with-Context view (`--with-context`) has not been run.
- **Not measured here:** cost per case, handling time and total run time are not recorded in the eval output. From separate runs of the batch runner on single cases: about 30 to 45 s and $0.07 to $0.13 per case when everything ran on Opus 5.5. The split setup has not been timed or costed, and no full batch has been timed.
- **Not run:** the 12 stress-test fixtures in `docs/stress-test/fixtures/` (including 109 and 111, which need a human) have not been put through this eval.
